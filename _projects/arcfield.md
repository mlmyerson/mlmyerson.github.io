A genetic algorithm searches complete curved-tile fields for layouts that minimize particle collisions under a shared, seeded traffic trial. A compact C simulation engine compiled to WebAssembly drives live evolutionary progress, a 3D fitness landscape, and exportable experiment history, all in an installable offline PWA.

**Stack:** JavaScript, C / WebAssembly, Python
